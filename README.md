# MaterialAnticipation
Data Analysis for behavioral and eye movement data  for an experiment to understand dynamic predictions made based on material properties.
The code requires the raw data that can be found here: https://osf.io/e39hp

The main functions to analyze the data are: 

'Main_Percept' --> This analyses the judgment data

'Main_Intercept' --> This analyses the eye tracking data for the main experiment

These scripts will perform the main analyses and will reproduce all Figures and Analyses shown in the manuscript.
Things that need to be adjusted are: 
The variable Datapath: Needs to point to the respective data folder that can be found on OSF
The variable Stimpath: Needs to point to the stimuli folder that can be found on OSF. 
resultpath and resultfiles should point to empty results folders in case some of the saving options are used.
